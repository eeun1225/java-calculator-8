# 🧮 문자열 덧셈 계산기

입력한 문자열에서 숫자를 추출해 더하는 계산기입니다.

---

## 🚀 기능 요구사항

- 기본 구분자: ,(쉼표), :(콜론)
- 커스텀 구분자 지정 가능 — //{구분자}\n{숫자들} 형식
- 빈 문자열 / null 입력 → 0 반환
- 잘못된 입력 → IllegalArgumentException 발생 후 애플리케이션 종료

---

## 🧱 구현할 기능

- [ ] **기본 입력 처리**
    - null 또는 빈 문자열("") 입력 시 0을 반환한다.

- [ ] **기본 구분자 처리**
    - 쉼표(,)와 콜론(:)을 구분자로 분리한다.

- [ ] **커스텀 구분자 처리**
    - 문자열 앞부분이 "//"로 시작하면 커스텀 구분자를 지정할 수 있다.
    - 커스텀 구분자는 "//"와 "\n" 사이의 문자를 사용한다.

- [ ] **문자열 숫자 변환 처리**
    - 분리된 문자열을 숫자로 변환한다.
    - 숫자가 아닌 값이 포함되면 IllegalArgumentException을 발생시킨다.

- [ ] **합계 계산**
    - 변환된 숫자들을 모두 더해 결과를 반환한다.

- [ ] **테스트 케이스 작성**
    - 각 단계별 기능이 정상 동작하는 단위 테스트를 작성한다.

---

## ⚠️ 예외 처리

- 입력이 잘못된 경우 → IllegalArgumentException 발생
- 예외 발생 시 프로그램은 종료
